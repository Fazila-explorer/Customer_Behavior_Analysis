# Customer Behaviour Analysis | Python, MySQL & Power BI

1. Overview

This project focuses on analysing customer shopping behaviour to identify purchasing patterns, spending trends, product preferences, and customer insights.

The project follows an end-to-end data analytics workflow, starting with data loading and exploration in Python, followed by data cleaning, SQL-based analysis using MySQL, and interactive dashboard development in Power BI.

A final analytical report and presentation were also prepared to communicate the key findings and insights.

2. Dataset

The project uses a customer shopping behaviour dataset containing information about customer demographics, purchasing habits, product categories, discounts, and subscription status.

Key dataset attributes include:
- Customer ID
- Age and Gender
- Item Purchased
- Product Category
- Purchase Amount
- Subscription Status
- Discount Applied
- Promo Code Used

7. How to Run the Project

Prerequisites
Install or configure the following:
- Python 3.x
- Jupyter Notebook
- MySQL Server and MySQL Workbench
- Power BI Desktop

Step 1: Clone the Repository

```bash
git clone https://github.com/Fazila-explorer/customer-behaviour-analysis.git
```

Step 2: Navigate to the Project Folder

```bash
cd customer-behaviour-analysis
```

### Step 3: Install Required Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter
```

Step 4: Run the Python Notebook

Open Jupyter Notebook:

```bash
jupyter notebook
```

Run the notebook to perform data loading, cleaning, EDA, and database preparation.

### Step 5: Run SQL Queries

- Open MySQL Workbench.
- Connect to your MySQL database.
- Select the project database.
- Execute the SQL queries provided in the repository.

Step 6: Open the Power BI Dashboard

- Open the `Customer_Shopping_Behavior.pbix` file using Power BI Desktop.
- Configure the MySQL connection if required.
- Refresh the data to view the dashboard.
